# Test fonts

The fonts the tests register with Pica (`test/test_helper.exs`), each a full original file exactly
as its project published it, with its licence beside it, copied from Pica's own test fonts. Lato
reserves its name under the SIL Open Font License, so a modified copy could not keep it.

The values the tests expect of them come from svglite measuring the same files in R, never from
Giggly or Pica: each test says how.
